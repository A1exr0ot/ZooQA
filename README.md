# ZooQA — проект по тестированию Java-кода

**ZooQA** — проект, созданный для отработки навыков написания юнит-тестов на Java.  
В рамках проекта реализована простая доменная модель животных, а основное внимание уделено качеству тестов, изоляции зависимостей и проверке покрытия кода.

> Проект предназначен для демонстрации практических навыков тестирования.

---

## 🎯 Цели обучения

- Освоить написание модульных тестов с использованием **JUnit 4**.
- Научиться применять **Mockito** для создания мок-объектов и проверки взаимодействий.
- Отработать параметризованные тесты для проверки нескольких сценариев.
- Понять, как настраивать **JaCoCo** для анализа покрытия кода.
- Закрепить принципы **SOLID** и разделения ответственности на небольшом примере.
- Научиться оформлять проект так, чтобы его можно было запустить и проверить одной командой.

---

## 🦁 О предметной области

Проект моделирует базовые сущности животного мира:

- `Animal` — базовый класс с методами `getFood(String)` и `getFamily()`.
- `Predator` — интерфейс для хищников с методом `eatMeat()`.
- `Feline` — семейство кошачьих, реализует `Predator`, умеет возвращать количество котят.
- `Cat` — домашняя кошка, использует `Feline` для звука и питания.
- `Lion` — лев с учётом пола, наличия гривы, еды и котят.
- `AlexLion` — конкретный персонаж: лев Алекс с друзьями, местом обитания и переопределённым количеством котят.

Несмотря на игровую тематику, главная ценность проекта — не сама модель, а **тесты**, которые её проверяют.

---

## 🧪 Чему учит проект

В ходе работы над проектом отрабатываются:

- создание мок-объектов через `Mockito.mock()`;
- настройка поведения моков через `when(...).thenReturn(...)`;
- проверка вызовов через `Mockito.verify(...)`;
- параметризованные тесты с `@RunWith(Parameterized.class)`;
- проверка исключений через `Assert.assertThrows(...)`;
- сравнение коллекций с учётом порядка и без него;
- настройка Maven-плагина JaCoCo для проверки покрытия.

```

├── Animal          // Базовый класс: еда, семейство
```

## 📈 Отчёты

Все отчёты формируются автоматически при `mvn clean verify`.

| Отчёт | Плагин | Путь | Формат |
|-------|--------|------|--------|
| Тесты | maven-surefire-plugin | `target/surefire-reports/` | TXT, XML |
| Покрытие | jacoco-maven-plugin (report) | `target/site/jacoco/index.html` | HTML, XML, CSV |
| Проверка покрытия | jacoco-maven-plugin (check) | консоль / лог сборки | текст |
| Данные покрытия | jacoco-maven-plugin (agent) | `target/jacoco.exec` | бинарный |

**Surefire** показывает, какие тесты прошли, упали или были пропущены.  
**JaCoCo** показывает, какие строки, методы и ветвления были выполнены, и падает со сборкой, если покрытие ниже 100%.

Пример успешного завершения:

```
Tests run: 15, Failures: 0, Errors: 0, Skipped: 0
All coverage checks have been met.
BUILD SUCCESS
```

## 📌 Особенности тестирования

- Для конструктора `Lion` написан отдельный параметризованный тест: проверяются допустимые и недопустимые значения пола.
- Для проверки наличия гривы используется параметризованный тест `LionHasManeTest`.
- В тестах применяются моки, чтобы не зависеть от реальной реализации `Feline`.
- Список друзей `AlexLion` сравнивается после сортировки — это делает тест независимым от порядка элементов.
- Проверяется не только результат, но и то, что были вызваны нужные методы зависимостей.

## 💡 Пример использования

```java
Feline feline = new Feline();
Lion lion = new Lion(feline, "Самец");

System.out.println(lion.doesHaveMane()); // true
System.out.println(lion.getKittens());    // 0
System.out.println(lion.getFood());       // [Животные, Птицы, Рыба]

AlexLion alex = new AlexLion(feline);
System.out.println(alex.getFriends());       // [Марти, Глория, Мелман]
System.out.println(alex.getPlaceOfLiving()); // Нью-Йоркский зоопарк
```

## 📚 Чему можно научиться на этом проекте

Проект показывает, как даже небольшая модель может быть покрыта качественными тестами.  
Он демонстрирует:

- как изолировать тестируемый класс от зависимостей;
- как проверять поведение, а не только результат;
- как использовать параметризацию для сокращения дублирования;
- как настроить автоматическую проверку покрытия в Maven;
- как читать и анализировать отчёты Surefire и JaCoCo.
